# Architecture Skeleton A1-A4

## Kanonische Quelle

Die vollständige Definition der Architekturstufen A1 bis A4, ihre
Trennfragen und die Datei-Matrix 1.0 stehen in:

`ARCHITECTURE_HUB_DEVELOPMENT/AH_MISSION.MD`

Abschnitt: `ARCHITEKTUR-SKELETT 1.0 — DRAFT`

Diese Datei enthält bewusst keine zweite Kopie der Matrix. Dadurch entstehen
keine zwei auseinanderlaufenden Wahrheiten während der Entwicklung.

## Kurzindex

- **A1 ONE_WAY-TOOL:** verantwortet ein Ergebnis; HUMAN validiert.
- **A2 AUTOMATION:** verantwortet einen vorgegebenen Ablauf; System validiert
  den definierten Endzustand.
- **A3 SINGLE-PROVIDER AGENT SYSTEM:** arbeitet sessionübergreifend innerhalb
  desselben Provider-Ökosystems.
- **A4 MULTI-PROVIDER SYSTEM:** überschreitet eine Provider- beziehungsweise
  unabhängige Modellfamiliengrenze.

## Promotionsregel

Nach HUMAN-Freigabe wird entschieden, ob das Skelett aus der Mission als
eigenständiger Standard in die Library promoviert wird. Bis dahin bleibt die
Mission die Single Source of Truth.
